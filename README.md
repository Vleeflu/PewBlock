# PewBlock

A Krunker.io-style first-person shooter written in **C# (.NET 10)** with **[Raylib-cs](https://github.com/ChrisDill/Raylib-cs)**.
Pick one of three modes from the main menu (click a card or press 1 / 2 / 3):

| Mode | Rules |
|---|---|
| **Deathmatch** | You + 11 bots on the 80 × 80 m arena, everyone vs everyone (bots fight each other too). Respawn after 2.5 s. First to 20 kills wins. |
| **Battle Royale** | You + 11 bots on a 180 × 180 m map (central tower, four ruined towns, four watchtowers, trees and rocks), everyone vs everyone, no respawns. A purple zone shrinks and hurts anyone outside it. Last one standing wins. When you're out, you spectate (click = next player, R = new match). |
| **Parkour** | The arena with no enemies. Practice bhop, air strafing, slides and crate jumps. The top bar shows your top speed. |

Deathmatch and battle royale start with a 5-second countdown. You can look around, but nobody can move or shoot until it shows **GO!**.

New to game programming? Read **[FUNDAMENTALS.md](FUNDAMENTALS.md)**. It explains every system in this project from the ground up.

## Download and play

Go to the repo's **Releases** page (right sidebar on GitHub), download `PewBlock-win-x64.zip`, unzip it, and run `PewBlock.exe`.
You don't need to install .NET; it's included in the exe.
Windows may show "Windows protected your PC" because the exe isn't code-signed. Click **More info → Run anyway**.

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Mouse | Aim |
| Left click | Shoot |
| Right click | Aim down sights / scope |
| Space | Jump. Hold it to bunny hop |
| Shift / C | Crouch. Press while running to slide |
| R | Reload |
| 1 / 2 / Mouse wheel | M4A4 / AWP |
| Tab | Scoreboard |
| Esc | Pause (from the pause menu, `[` and `]` change sensitivity, default 1.00, M goes to the main menu, and Q quits) |
| R / M (match over) | Play the same mode again / back to the main menu |

## Movement tech (like Krunker)

- **Bunny hop:** hold Space. Each time you land, you jump again on the same tick, so ground friction never slows you.
- **Air strafe:** while in the air, hold A or D (not W) and turn the mouse smoothly toward that side. You gain speed.
- **Slide:** press Shift while running fast. Press it in mid-air and the slide starts when you land (slide-hop).
- **Crouch-jump:** crouching in the air pulls your legs up, so you can clear ledges 0.6 m higher.

The bottom-center meter shows your speed. Base running speed is 7.5 m/s. Good air strafing can reach 18+.

## Sounds

Gun sounds live in `source/`. The build copies them next to the exe, so they work with `dotnet run` and with the standalone exe.

| File | Used for |
|---|---|
| `source/burst.mp3` | M4A4 (yours and every bot's) |
| `source/sniper.mp3` | AWP |

- **Replace a sound:** overwrite the file with the same name (`.mp3`, `.wav` or `.ogg`).
- **Use a different file for a weapon:** change `Sound:` in `src/Weapon.cs`.
- Silence at the start and end of a file is trimmed automatically when it loads.
- Bot gunshots get quieter with distance and come from the left or right speaker, depending on where the bot is.
- If a file is missing, the game still runs; that weapon is just silent.

## Textures

Every surface (grass, sand, concrete, bricks, crates, tread plate, rock, bark, leaves, sandbags, uniform camo, leather, skin, hair, gun metal, polymer) has a PNG texture in `assets/textures/`. The build copies them next to the exe.

They are generated by a small separate program, `tools/AssetGen`. To change how they look, edit a recipe in `tools/AssetGen/Program.cs` and rerun it from the repo root:

```
dotnet run --project tools/AssetGen
```

- The textures are **grayscale**. The game multiplies them by each block's or body part's color, so one fabric texture gives every bot camo in their own color.
- **Use your own image instead:** save a PNG with the same name in `assets/textures/`. For colors to stay right, keep it grayscale and mostly light. How many meters one copy covers is set in `src/Textures.cs`.
- If a file is missing, the game still runs; that surface is just a plain color.

## Project layout

| File | What it does |
|---|---|
| `Program.cs` | Entry point |
| `src/Game.cs` | Game loop, fixed timestep, game modes, match flow and pre-match countdown, shooting |
| `src/Player.cs` | Player movement, crouch/slide, health, recoil, first-person gun and arms |
| `src/Movement.cs` | Quake-style friction and acceleration (bhop and air strafe math) |
| `src/KinematicBody.cs` | Box collision against the map, stair stepping |
| `src/World.cs` | Both maps (arena, battle royale), what each block is made of, raycasts, line-of-sight checks |
| `src/Bot.cs` | Enemy AI: target selection, combat, wandering, zone awareness; soldier model |
| `src/Combatant.cs` | `ICombatant`, shared by the player and bots, plus health/respawn rules |
| `src/Zone.cs` | Shrinking battle royale circle |
| `src/Weapon.cs` | Weapon stats, ammo, reload, fire rate, which model and sound each gun uses |
| `src/GunModel.cs` | M4A4 and AWP models, muzzle flash |
| `src/Audio.cs` | Loads gun sounds, overlapping playback, distance volume and left/right panning |
| `src/Effects.cs` | Tracers and particles |
| `src/Hud.cs` | Crosshair, scope, health, ammo, kill feed, minimap, countdown, mode menu and per-mode screens |
| `src/Render.cs` | Box and cylinder drawing with flat per-face shading and tiling textures |
| `src/Textures.cs` | Loads the PNG textures, sets how many meters each one covers |
| `tools/AssetGen/` | Separate program that generates the textures in `assets/textures/` |
